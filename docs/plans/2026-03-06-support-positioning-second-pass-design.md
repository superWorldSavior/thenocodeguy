# Support-First Positioning Second Pass Design

## Goal

Align the remaining French marketing pages with the service-led positioning already applied to the homepage and contact funnel. The site should consistently sell supervised AI assistants deployed with setup, training, support, and human escalation instead of sounding like a human replacement pitch.

## Scope

This second pass covers:

- `/agent-ia`
- `/domaines/btp`
- `/domaines/commerce`
- `/domaines/admin`
- `/domaines/web`
- `/domaines/btp/facturation-electronique`
- Supporting FR narrative copy still visible on `/a-propos` and `/blog`
- Localized metadata for the pages above

This pass does not rewrite the FR blog articles themselves or the EN/ZH locales.

## Positioning Rules

Across these pages, we should remove or sharply reduce:

- "autonomous", "never sleeps", "24/7" as the core promise
- "recruit/hire an AI agent"
- comparisons that frame the offer as a replacement for an employee

We should consistently emphasize:

- setup and scoping
- supervised deployment
- onboarding and training
- human support, SAV, and escalation on sensitive cases

## Page Strategy

### Agent IA explainer

Keep the existing structure, but shift it from "what is an autonomous collaborator" to "how a supervised AI assistant fits into a team." The comparison section should stop opposing the offer to a full-time employee and instead compare unsupported tooling with accompanied deployment.

### Sector pages

Keep the before/after pattern because it is commercially useful, but change the framing around the page title, metadata, CTA support text, and FAQ. Each page should make it explicit that the human team keeps the final relationship, validation, or escalation path.

### BTP electronic invoicing page

Move from "hire an agent that handles everything" to "we connect the approved platforms, encode the rules, and train the team." This page should feel safer and more implementation-oriented.

### About and blog framing

These pages still leak "staffing/autonomous/no human intervention" language. They should reinforce that TheNoCodeGuy is an implementation partner, not an AI staffing marketplace.

## SEO

The sector and explainer pages currently have basic metadata only. This pass should add localized canonical and open graph URLs, while rewriting descriptions around supervised deployment, training, and support.

## Recommendation

Do not expand the architecture. The fastest credible gain is to change the messaging where intent and conversion happen already, then validate that the new positioning is enforced by a regression test.
