# Research: Facturation Électronique BTP

**Feature ID**: 004-facturation-electronique
**Date**: 2026-02-26

---

## Decision 1: Calendrier réglementaire

**Decision**: Utiliser les dates confirmées de la réforme dans tout le contenu marketing.
**Rationale**: Les dates sont définitives (pas de nouveau report depuis le décalage 2024→2026).
**Détails**:
- 1er septembre 2026 : réception obligatoire pour TOUTES les entreprises + émission GE/ETI
- 1er septembre 2027 : émission obligatoire PME/micro-entreprises
- Les TPE/PME BTP doivent être prêtes en RÉCEPTION dès sept. 2026 (leurs clients GE/ETI émettront)
**Sources**: service-public.fr, economie.gouv.fr, Cegid, Pennylane

## Decision 2: Terminologie PA vs PDP

**Decision**: Utiliser "Plateforme Agréée (PA)" et non "PDP" dans le contenu.
**Rationale**: Depuis juillet 2025, la DGFiP a renommé les PDP en PA. Utiliser le terme officiel actuel.
**Alternatives**: Mentionner "(anciennement PDP)" une fois pour la clarté, puis utiliser PA systématiquement.

## Decision 3: Liste des PA à mentionner

**Decision**: Citer les PA les plus connues du secteur BTP sans prétendre être exhaustif.
**Rationale**: ~110 PA agréées au total, impossible de toutes les lister. Citer les plus pertinentes BTP.
**PA à citer**:
- Chorus Pro (marchés publics — obligatoire)
- Sage / Batigest Connect (ERP BTP majeur)
- Cegid (comptabilité PME)
- Pennylane (fintech comptable)
- Batappli / Cecurity (logiciel BTP, PA gratuite)
- Yooz (dématérialisation factures fournisseurs)
- Dext (OCR + IA)
- Docaposte / SERES
- Qonto (néobanque pro)

## Decision 4: Spécificités BTP à couvrir

**Decision**: Mettre en avant 5 spécificités BTP dans le contenu.
**Rationale**: Ce sont les points de douleur les plus forts et les plus différenciants.
**Spécificités**:
1. **Situations de travaux** : facturation à l'avancement (% cumul, déductions)
2. **Retenue de garantie 5%** : codification dans le format électronique, déblocage à 12 mois
3. **Auto-liquidation TVA sous-traitance** : code régime TVA spécifique, e-reporting
4. **Acomptes** : factures d'acompte avant démarrage travaux
5. **Decompte Général Définitif (DGD)** : clôture de chantier dématérialisée

## Decision 5: Angle marketing — pitch principal

**Decision**: Pitcher sur la fragmentation des PA, pas sur la conformité.
**Rationale**: La conformité est un problème que toutes les solutions résolvent. La fragmentation (jongler entre 3-5 PA) est le vrai point de douleur que personne ne résout.
**Pitch**: "Votre assistante gère déjà les devis, le suivi de chantier, les relances, la paie. Ne lui ajoutez pas 5 plateformes à maîtriser en 6 mois. Recrutez un agent IA qui fait le pont."
**Alternatives**: Pitch conformité ("Soyez prêt pour 2026") — trop générique, tout le monde le dit.

## Decision 6: Positionnement concurrentiel

**Decision**: Positionner TNCG sur l'intersection "IA agentique + multi-PA + spécificités BTP + PME/TPE".
**Rationale**: Aucun concurrent identifié sur cette intersection.
**Concurrents analysés**:
- Dext : IA prévue mais généraliste, pas BTP
- Tradeshift (Ada) : international, pas BTP
- SAP BTP + IA : grands comptes seulement
- Graneet, Batappli, Batigest : spécialisés BTP mais PA unique, pas d'IA
- Pennylane : PA + compta automatisée mais pas BTP

## Decision 7: Structure de la landing page

**Decision**: Suivre le pattern des pages domaines existantes (hero + sections avant/après + référence client + CTA bottom).
**Rationale**: Cohérence avec le design system existant. Pattern prouvé.
**Sections**:
1. Hero : badge urgence + titre + sous-titre + CTA + trust line
2. Le problème : "Ce qui vous attend en septembre 2026" (3-4 points de douleur)
3. Avant/Après : 4-5 comparaisons concrètes
4. Spécificités BTP gérées : liste des 5 spécificités
5. PA compatibles : grille de logos/noms
6. Comment ça marche : 3 étapes simples
7. CTA bottom : CalPopupButton + trust line
