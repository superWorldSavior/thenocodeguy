# Implementation Plan: Cal.com Booking Integration

**Branch**: `003-cal-booking` | **Date**: 2026-02-26 | **Spec**: [spec.md](./spec.md)
**Input**: Feature specification from `/specs/003-cal-booking/spec.md`

## Summary

Intégrer Cal.com en tant que système de booking directement dans les CTAs du site. Popup sur les CTAs haute intention (hero, CTA section, nav, missions, domaines, agents, pricing), inline sur la page /contact redesignée. Refonte du wording CTA ("Demander une démo" → "Réserver un appel découverte"). Le formulaire Formspree reste comme chemin secondaire sur /contact.

## Technical Context

**Language/Version**: TypeScript 5 (strict mode) + Next.js 16.1.6 (App Router)
**Primary Dependencies**: @calcom/embed-react@1.5.3 (NEW), next-intl, shadcn/ui, Tailwind CSS v4, lucide-react
**Storage**: N/A (Cal.com gère les bookings, Formspree gère les formulaires)
**Testing**: Build verification (`npm run build`), grep validation wording
**Target Platform**: Web (Vercel hosting), desktop + mobile
**Project Type**: web-service (marketing site)
**Performance Goals**: Zero impact LCP/CLS — Cal.com embed est lazy-loaded (popup) ou chargé uniquement sur /contact (inline)
**Constraints**: SSR-safe (dynamic import ssr: false), dark mode compatible, 4 locales
**Scale/Scope**: ~15 composants/pages touchés pour le wording, 2 nouveaux composants Cal.com, 1 page redesignée

## Implementation Phases

### Phase 1: Setup & Composants Cal.com

1. Installer `@calcom/embed-react@1.5.3`
2. Créer `CalPopupButton` — client component avec `getCalApi`, `data-cal-link`, namespace, theming
3. Créer `CalInlineEmbed` — client component avec `Cal` inline, dynamic import ssr: false, namespace
4. Les deux composants acceptent un `calLink` prop et un `theme` prop synchronisé avec next-themes

### Phase 2: Wording CTA — Messages FR

1. Remplacer tous les "Demander une démo — 15 min" → "Réserver un appel découverte"
2. Ajouter les trust lines dans les traductions : "30 min avec Erwan — gratuit, sans engagement"
3. Ajouter les variantes contextuelles pour les pages domaines
4. Corriger "Voir ce qu'on automatise" (hero) → "Réserver un appel découverte" si pertinent selon tier

### Phase 3: Brancher les CTAs Tier 1 (Popup)

1. HeroCarousel — primary CTA → CalPopupButton
2. CTASection — button → CalPopupButton
3. MissionsSection — CTA → CalPopupButton
4. Navigation — desktop + mobile CTA → CalPopupButton

### Phase 4: Brancher les CTAs Tier 2 (Popup)

1. Pages domaines (BTP, Commerce, Admin, Web) — hero + bottom CTAs → CalPopupButton
2. Agents page — CTA → CalPopupButton
3. Pricing page — CTA → CalPopupButton

### Phase 5: Redesign /contact

1. Restructurer page.tsx — CalInlineEmbed en haut (75% poids visuel) + section "Vous préférez écrire ?"
2. Simplifier ContactForm — optionnellement collapsible, champs réduits
3. Trust signals sur la page

### Phase 6: Sync locales EN, ZH-TW, ZH-CN

1. Traduire tous les nouveaux wordings CTA et trust lines
2. Culturellement adapté (pas littéral)

### Phase 7: Build & Validation

1. `npm run build` — zero errors
2. Grep validation — zero "démo" ou "15 min" dans les CTAs
3. Vérification visuelle dark/light mode
